You will read the text of a Community Note: a short note that adds context to a social media post.

Write the single central factual claim that the note asserts, as one neutral sentence in English.

Rules:
- State the claim itself, not that "the note says" it.
- Keep the specific facts that make it checkable: names, numbers, dates, places.
- Leave out URLs, source names, hedging, and any judgement of the original post.
- If the note asserts several claims, keep the one the rest of the note depends on.
- Also give the ISO 639-1 code of the language the note is written in.
